# My Rogue

Rust と bracket-lib で作るローグライク。Lua から Entity の設定と行動関数を読み込みます。

設計の基準は [クラス図](document/class.pu) と [基本ループ](document/basic_algorism.pu)。
制作ルールの初期案は [document/production](document/production/README.md) にまとめています（未実装の提案を含みます）。
世界観に合わせた[32色パレット案「Ash & Rust」](document/color_thema/README.md)も用意しています。
全78定義に対応する[32×32 Entityテクスチャ](data/entity_tex/README.md)と[透過の重ね合わせ一覧](data/entity_tex/index.html)もあります（全78定義に専用画像を接続済み）。
`GameState::tick` から `Game::input → update → render` を一巡します。死亡時はHP・水分を回復し、三栄養を各50へ戻し、所持品と世界を維持して初期位置へリスポーンします。初期位置が塞がっている場合は近くの空きマスへ復帰します。終了はCtrl+Qです。Escは画面を閉じる・選択を中止する操作に使います。

## 起動

```sh
cargo run
```

既定で、全Entityを試せる左上倉庫のマップが起動します。ウィンドウ表示の場合:

```sh
cargo run -- --windowed
```

左上の石壁付き倉庫に全試験用アイテムと開始位置、右側に敵11種の個室と爆発試験室、左下に固定物・地形を配置しています。
配置と試し方は[Entityテストマップ](document/entity_test_map.md)を参照してください。
`--check-data`、`--simulate 100` でGUIなしでも検査できます。従来の通常マップは `cargo run -- --normal-map` で起動できます。`--test-map` も互換用に残しています。

フルスクリーンで起動し、80×50 セルの画面全体（文字・マップ・UI）を拡大表示します。
ウィンドウ表示にする場合は `cargo run -- --windowed`。初期サイズは1280×800で、サイズ変更時も UI 全体を拡大・縮小します。
Lua の地面・木・壁・池・敵・アイテムを32×32 PNGで表示します。
背景6種は3色の控えめな質感を付け、道は隣接地形に合わせて縦・横・曲がり角・分岐を自動でつなぎます。
同じ役割の画像候補は [texture_rules.json](data/entity_tex/texture_rules.json) に追加でき、場所ごとに安定して選ばれます（現在は各1候補）。
画像はAsh & Rust 32色・二値アルファに制限し、起動時にも検査します。`--ascii` で従来の文字表示に切り替えられます。
素材の32×32は元画像の解像度で、画面上のサイズはウィンドウ・DPI・全体の拡大率に依存します。
同梱フォントでステータス・操作案内・所持品名・通常ログを日本語表示します。
`+` / `-` でマップだけを1〜4倍に拡大・縮小できます（初期1倍）。拡大中はプレイヤー、調査・照準中はカーソルや選択対象を追従します。
文字UIは同じ大きさを保ち、ラベル・照準・弾道はマップと一緒に拡大します。右上の `Zoom` で倍率を確認できます。

走行はv（Velocity）で切り替え、同じ移動キーを使います。2マスで世界が1ターン進み、1マスでスタミナ5を消費（上限100）。尽きると歩行へ戻ります。走行OFF中は最大5/世界ターン回復し、回復20につき炭水化物1を使います。炭水化物0では回復停止。攻撃速度は変わらず、脚切断時は走れません。

棍棒は1d2+4（5〜6）、メイスは1d2+5（6〜7）で、鈍器は安定した威力を持ちます。数値は貫通1回あたりです。

方向キーは押下時に一歩移動し、押し続けると350ms後から180ms間隔で繰り返します。hjklyubnと矢印に適用し、メニュー・射撃演出中は移動を繰り返しません。短い押下もキー解放イベントと分けて受け取ります。

通常画面のマップ右側に、プレイヤー自身を除く足元の生物・地形・固定物・設備・品物を種類と名前で表示します。内部IDは表示せず、品物の個数と短い効果説明を示します。武器は威力・貫通・射程、防具は防御・回避、その他の品は用途や栄養・HP・水分の回復量を確認できます。重なった地形や同種の別スタックも別々に載り、長い名前は折り返します。多い場合はPageUp/PageDownで全行を確認でき、移動すると先頭へ戻ります。所持品や隣のマスは一覧に含めません。

プレイヤーの定義は `data/entity_templates/player.lua`、操作仕様は `document/entity_document/player_entity.md`。射撃前に r で装填してください。弾倉容量はゲーム用の仮設定でグロック15発・SKS10発・クロスボウ1発です。

射撃の対象は、装備武器の射程と視界内にいて射線が通る、生存中の可動Entityです。戦闘・装備・LuaエラーのログはEntity名で表示します。

敵を「調べる」か射撃対象として選ぶと、正確なHPの数値ではなく「元気・軽症・重症・瀕死」の目安を表示します。頭・胴体・左右の腕脚は「異常なし・出血・大出血・切断」で表示し、視野外の敵の状態は表示しません。

HPは全体で一つです。近接・射撃で貫通して正のダメージが決まった後、武器の `critical_value` 以上が2D6で出ればクリティカルです。切断されていない部位を均等に一つ選び、「異常なし → 出血 → 大出血 → 切断」と一段階進みます。全武器に値を必須設定し、仮値はナイフ10・棍棒12・グロック/SKS11・クロスボウ10。武器の詳細画面にも表示します。全体HPが0、または頭・胴体が切断されると死亡します。負傷部位ごとに出血1・大出血2・切断4の継続ダメージを毎ターン合算します。片脚切断は移動1マスに4ターン、両脚切断は8ターンかかります。包帯で部位ごとに止血できます。切断部位の再生は未実装です。

武器と盾を左右の手に装備できます。所持品でwを押し、j/kで対応する持ち方を選んで1〜9・0を押すと、その数字に登録して装備します。通常画面で同じ数字を押すと登録した持ち方に切り替わります。解除は装備中の品だけに表示します。包帯・食料・工具などは装備しません。切断した手の装備は残りますが使用不可。利き手はLuaの `movable.dominant_hand`（right/left、既定right）で設定し、逆手の武器は最終ダメージ3/4（端数切捨て）です。SKSとクロスボウは両手専用、拳銃は片手・両手対応。グロックの片手持ちは射程4・命中−1、両手持ちは射程6・命中補正なしの仮設定です。棍棒も片手・両手対応で、両手持ちではPV＋1。これらは[Luaの装備設定](document/entity_lua.md#左右の手利き手と持ち方)で変更できます。

包帯・注射器・ビタミン剤・食料・飲料・手榴弾も所持品でw→数字で登録できます。登録だけでは消費せず、ターンも進みません。通常画面の数字キーで使用し、同じ種類の補充品にも割り当てが残ります。武器は個々の品と持ち方を登録し、置くと解除されます。

包帯は所持品でEnter、または登録した数字を押し、出血中でまだ包帯を巻いていない部位だけから選びます。確定で一個使い、一ターン進みます。処置中も出血ダメージは続き、開始から100世界ターン経過すると止血し、巻いた包帯が自動で消えます。処置中に同じ部位へクリティカルを受けると負傷は「出血→大出血→切断」と進みます。処置期限はそのままです。止血後も負傷段階・切断状態は保持し、未切断部位へ再度クリティカルを受ければ一段階進んで再出血します。

射撃すると、銃は黄色い光の弾道、クロスボウは水色の矢が飛ぶ演出を表示します。命中は `*`、回避は `x` を短く表示します。敵の射撃にも対応し、視界外の弾道は表示しません。演出中は次の行動を受け付けず、Ctrl+Qで終了できます。演出によって追加のターンや弾薬は消費しません。

手榴弾を投げると、風切り音とともに緑の `o` が投擲先まで飛びます。着弾に合わせて爆発音が鳴り、中心から5×5へ範囲が広がって薄れます。爆発は黄・橙の `*`、閃光は白・水色の `+` と背景色で区別します。壁で遮られる範囲と視界外は表示しません。演出中の行動待機・Ctrl+Qは射撃と共通で、追加の消費や被害はありません。

所持品・装備欄・調べる画面で、武器の `1d6+1` などのダイスとPV、プレイヤーや可動EntityのAV・DVを確認できます。射撃のPV・ダメージは武器側で決まります（例：グロック `1d6+1`）。弾薬は対応する武器の装填・射撃で消費する品物で、独自のダメージ値は持ちません。防具は所持品でw一回で着脱し、数字に登録しません。同じ装着部位の防具は交換し、着用中のAV・DVを合算します。仮マップの(10,11)に革の鎧（AV1・DV0）を配置しています。

敵のいるマスへの移動でも攻撃します。プレイヤー・敵とも、縦横の片側や両側に壁があっても斜め移動・斜め近接攻撃ができます。移動先そのものが壁や他のEntityで塞がれている場合は移動できません。所持品などの画面を開くだけではターンは進みません。

bracket-lib の視野計算を使い、プレイヤーの `sight_range` 内だけを表示します。壁・木など `collision.sight = true` のEntityは視界を遮り、その向こう側の地面・生物・アイテムを隠します。視界外は黒く表示し、「調べる」と射撃対象の選択でも隠れたEntityを表示しません。探索済み地形の記憶表示は未実装です。

固定EntityのLua定義では `static.movement_cost = 2.0` のように経路コストを設定できます（省略時1、0.01〜1000）。値が小さい地形ほど経路探索で優先します。同梱設定は道1.0・野原2.0です。地形コスト自体は移動時間を変えません。脚の切断による4/8ターンの移動時間は別に適用します。重なった地形の扱いなどは[固定Entityの仕様](document/entity_document/static_entity.md#移動コスト)を参照してください。

初期位置から `e → u` で近くの宝箱を操作できます。西側には扉付きの建物と室内の宝箱を配置しています。扉は開閉でき、宝箱自体も拾えます。所持品では `e` で詳細を開き、Enterで宝箱の行動メニューへ進めます。開くと中身の一覧が表示されます。j/k・上下矢印で移動し、Spaceで複数選択、Enterで選んだ品を直接取得します。未選択の品は箱に残り、Escで取得せず戻れます。行動のLua登録方法と配置座標は[インタラクト仕様](document/interactions.md)を参照してください。

追加した武器・食品・固定物はマップ南東の展示区画（x=22〜40、y=23〜27）に配置しています。追加グール8種は東部（x=39〜51、y=18・23）に配置しています。能力・栄養・威力は仮設定です。

槍は射程2の両手近接武器です。装備後にf、または所持品Enterで敵選択を開き、hjklyubn/矢印で敵を切り替えてEnter/fで攻撃します。隣接する敵へは通常画面で方向を押すだけでも攻撃します。射程2以上の全近接武器を同じ操作で使えます。手榴弾は所持品Enterからマスを指定します。投擲射程は6、効果範囲は5×5で、中心・隣接・外周へ爆発被害24/16/8または閃光の行動不能3/2/1ターンと減衰します。自分や味方も巻き込み、壁で遮られます。選択と中止は無料、投擲確定で一ターン・一個消費です。AK・M16はライフル弾を装填して一発ずつ射撃します。

## レベルと技能

敵を倒して経験値を得るとレベルが上がり、筋力・体力・敏捷・器用さ・知力・精神力のうち1つ以上が各1、最大HPが1〜10増えます。次レベルの必要経験値は100×現在レベル。通常画面上部に進捗を表示します。

技能は攻撃・射撃・投擲・盾を用いた防御・制作の使用回数で成長します。`@` の【技能】で次に上がるまでの回数を確認できます。死亡後も成長を保持します。調整値・各技能の効果と未実装の専用操作は[成長仕様](document/progression.md)にまとめています。調整値は `data/progression.lua`、敵の経験値は各Luaの `movable.experience_reward` です。

通常・試験マップは60×38マス。操作案内・ログ・数字登録を画面下へまとめ、UIはgruvboxを参考にした配色へ統一しています。

## Lua の編集と確認

タンパク質・炭水化物・ビタミンは初期値50、上限100です。満腹度は廃止し、炭水化物は通常20ターンで1減り、攻撃時は消費が2倍になります（攻撃だけなら10ターンで1）。ビタミンは20世界ターンごとに1減ります。正常でタンパク質がある間は毎ターンHP1を自然回復し、回復したHP1につきタンパク質1を消費します。満タン時は消費しません。食品は不足している栄養を直接補います。ビタミン0で100ターンごとに1/6で「正常→風邪→肺炎」と進行し、ビタミン1以上なら100ターンごとに1/2で一段階ずつ回復します。風邪・肺炎では自然回復が停止。肺炎では移動に使った累計10ターンごとにHP1を失います（下限1）。詳しくは[食料ルール](rule/food.md)を参照してください。

Lua の変更は再起動時に反映します。既定ではビルド元プロジェクトを基準に読むため、
実行時のカレントディレクトリには依存しません。別の設定一式は `--root /path/to/project` で指定できます。

```sh
cargo run -- --check-data
cargo run -- --simulate 20
cargo test
cargo fmt -- --check
cargo clippy --all-targets
luajit tools/check_entity_templates.lua
luajit tools/test_entity_behaviors.lua
luajit tools/test_interactions.lua
luajit tools/test_food_rules.lua
```

`--check-data` と `--simulate` はウィンドウを作らず実行できます。
保存・復元、探索済み地形の記憶表示は未実装です。制作はLua定義の12レシピに対応し、pで選択、Enterで1ターン作業します。所持品・足元と隣接8マス・そこにある宝箱の中（閉状態も含む）の材料と工具を使います。道具の要求レベルは必須、スキル未達でも挑戦可能。現在の条件で作れないレシピはグレー表示し、選択すると不足理由を確認できます。成功率と完成品の出来を画面で確認できます。
倉庫の(4,17)へ移動すると、作業台(4,18)と制作ストレージ(5,17)を使って試せます。ナイフを所持してpを開いてください。成功・失敗とも作業時間を使い、失敗時は材料の半分（切上げ）を失います。完成品は所持できる分をインベントリへ入れ、重量・容量・長さの制限で入らない分は足元に置きます。武器の出来はダメージ固定値、耐久品の出来は耐久性へ反映。食品・包帯・弾薬は当面標準品質です。[レシピと確率の編集方法](document/production/lua.md)を参照してください。

## 効果音

近接攻撃・銃声・クロスボウ・リロード・投擲・爆発・閃光のWAVを [data/sound](data/sound/README.md) に置いています。
Python標準ライブラリのみで合成し、`python3 tools/generate_sounds.py` で再生成できます。
近接攻撃（素手を含む）・銃撃・クロスボウ・装填成功時に再生します。リロード音は0.68秒の共通操作音で、失敗時は鳴りません。敵の装填音は視野内のみで鳴ります。回避されても攻撃音は鳴り、空撃ちや射程外では鳴りません。
射撃音は弾道演出の開始に合わせます。敵の近接は攻撃者が視界内にいる場合、射撃は弾道の一部が発射時の視界内にある場合に鳴ります。
投擲音は飛翔開始、爆発音・閃光音は着弾時にそれぞれ一度だけ鳴ります。失敗・中止した投擲では鳴りません。
`cargo run -- --mute` で無音にできます。音声デバイスやWAVの読み込みに失敗した場合は、標準エラーへ理由を出して無音で継続します。
WAVは `--root` の指定先（既定はプロジェクト）から読みます。`--check-data` / `--simulate` は音声デバイスを使いません。

## 依存ライブラリ

bracket-lib は GitHub master のコミット `ce9124ad744553b2576e44df44e94b0f72faa8e8` を Cargo.lock に固定。
描画・入力・視野・弾道の線計算に加え、敵の追跡にゲーム側の重み付きDijkstra、戦闘乱数にシード付きのRandomNumberGeneratorを使用します。乱数生成器の切替前とは同じシードでも戦闘結果が変わりますが、同じ版・同じシード・同じ操作での再現性は維持します。
地形生成を追加する際はbracket-libのノイズも利用する方針です。現在の試験用マップはLuaの固定配置です。
Lua は mlua の lua54 / vendored 機能で組み込むため、ゲームの起動に外部 Lua コマンドは不要です。
効果音は rodio 0.21.1（playback / wav）で非同期再生します。
上記 Lua 単体検査のみ LuaJIT が必要です。

依存更新を依頼する場合のコマンドは `cargo update -p bracket-lib`。
API の補足は既存の [スキル参照資料](skills/bracket-lib/references/braket_lib.md) にあります。
