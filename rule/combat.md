# 戦闘ルール

Caves of Qud を参考にした本ゲームの戦闘ルール案。
以前の「条件成立で必ず命中し固定ダメージ」という案を置き換える。
初回 Rust 実装で AV・DV・PV とダメージダイスを接続済み。
Lua は schema_version 2 に移行し、旧形式の数値 damage は拒否する。

## 参考にする構造と、本ゲームでの変更

Qud は命中、貫通、被害を段階的に判定する。DV は命中しにくさ、AV は装甲、
PV は攻撃の貫通力を表し、貫通が複数回成立するとダメージダイスを複数組適用する。
[公式 Wiki の PV 解説](https://wiki.cavesofqud.com/wiki/PV) を参考にする。

本ゲームでもこの三段階を採用する。以下の数式・初期値は本ゲーム独自の案。
原作の爆発ダイス、筋力上限と再判定の厳密な順序、会心の武器種別効果などは再現しない。
射撃も原作の弾道のずれを再現せず、初期案では近接と共通の命中式を使う。
[原作の射撃処理](https://wiki.cavesofqud.com/wiki/Missile_weapon_combat) とは異なる。

## 行動と処理の担当

- Rust は Entity enum の Movable / Static / Item で処理を分岐する。
- Lua は攻撃する相手や移動先を選ぶ。HP・弾薬・所持品・位置の変更は Rust が行う。
- movable の on_turn は attack Action、武器の on_use は weapon_attack 効果要求を返す。
- 攻撃は一回で一ターンを使う。攻撃命令と武器の使用処理で二重にターンを消費しない。
- 受け付けた時間消費行動が適用時の再検証で失敗しても、そのターンは待機として消費する。
- 対象不在・射程外・弾薬不足など、攻撃の成立条件を満たさない場合は被害も弾薬消費も発生しない。
- 攻撃が成立した後の「回避された」「装甲を貫けなかった」は有効な攻撃結果として扱う。射撃なら弾薬を消費する。
- 製作・所持品・マップの画面を開くだけなら時間を進めない。

## 攻撃できる条件

攻撃者と対象が存在し、攻撃者が生存し、対象が攻撃者自身でないことを確認する。
対象は生きた movable または耐久を持つ破壊可能な static とする。
耐久を持たない野原・道・池には被害を与えない。所持品への直接攻撃は初期ルールに含めない。

距離は同じ z におけるチェビシェフ距離 `max(abs(dx), abs(dy))` を使う。
近接は距離 1 の八方向。プレイヤー・敵とも、斜め方向の間にある縦横の片側または両側に壁があっても攻撃できる。
射撃は武器の射程以内で、対象まで視線が通っている必要がある。
敵 AI は faction から敵を選ぶが、プレイヤーが指定した相手への攻撃可否は敵対関係と別に判定する。

## 武器と弾薬

武器を指定した場合は、攻撃者が所持・手に装備し、耐久が残り、持ち方と必要な手が使用可能であることを確認する。
未指定なら loadout などで装備した武器を試し、使用不可なら素手の近接攻撃を試す。
明示的に指定した武器が使用不可の場合は、別の武器へ自動で変更せず失敗とする。

| 攻撃方法 | ダメージダイスの設定元 | 射程 | 消費 |
| --- | --- | --- | --- |
| 素手 | movable.attack.damage | movable.attack.range（初期値 1） | なし |
| 近接武器 | item.weapon.damage | item.weapon.range（1） | なし |
| 遠距離武器 | item.weapon.damage | item.weapon.range | 対応弾薬を ammo_per_attack 個 |

ダイスは `5d5+1` のように表示する。近接・遠距離とも武器の weapon.damage にダイスと補正をまとめて持つ。グロックは `1d6+1`、SKSは `1d8+2`、クロスボウは `1d8`。各貫通でこのダイスを独立に振り、補正後の被害は0未満にならない。PV・射程・命中補正も武器が持つ。弾薬は対応種類と消費数を管理し、ダメージ値は持たない。一般的な鉛弾銃の威力を銃側で決めるQudの構成を参考に、本作ではクロスボウにも同じ分担を用いる。

所持品・装備欄・調べる画面にダイスとPV、可動EntityにAV・DVを表示する。item.armor = { slot, av, dv }を持つ防具は手とは別枠へ着用し、各部位一品。着用中の防具と使用可能な盾のAV・DVを合算する。耐久0の品は加算しない。

player_entity.md の操作仕様に従い、f は装備した遠距離武器で射撃、r は一ターンで装填する。magazine_capacity のある武器は未装填で生成し、所持品の対応弾薬を弾倉の空きまで移す。グロック15発・SKS10発・クロスボウ1発を仮設定とする。射撃時は装填済み弾薬を消費する。未指定の旧定義のみ所持品から直接消費する。
必要な個数は複数スタックから合計して判定する。
攻撃の成立条件と残弾を検証してから、弾薬消費と判定結果をまとめて適用する。
回避・非貫通で被害が 0 でも、発射した弾薬は戻らない。
Lua のエラーなどで攻撃要求自体を破棄する場合は発射も被害も適用しない。
初期ルールでは武器耐久の自動減少は行わない。

## 全体HP・部位の負傷とクリティカル

部位別HPは廃止し、全体HPを一つ持つ。Luaでは `movable.hp = 60`、`movable.body = { "head", "body", "left_arm", "right_arm", "left_leg", "right_leg" }` を指定する。bodyはこの六部位を重複なく登録する。各部位は数値HPではなく `healthy → bleeding → heavy_bleeding → severed`（異常なし → 出血 → 大出血 → 切断）の状態を持つ。

命中 → PVによる貫通 → 貫通回数分のダメージダイス → クリティカルの順で判定する。生物に正のダメージが出た武器攻撃に限り、2D6を一度振り、合計が `item.weapon.critical_value` 以上ならクリティカルとなる。ダメージ倍率は追加しない。複数貫通でも判定・段階進行は一回。クリティカル時のみ、未切断の部位から均等に一つを選び一段階進める。通常のダメージは全体HPを減らす。

全ての装備可能な武器でcritical_valueを必須とし、整数2〜12を受け付ける。近接・射撃・敵味方で同じ処理を使う。仮値は以下。

| 武器 | critical_value | 判定成功率（正の被害が出た後） |
| --- | --- | --- |
| ナイフ | 10 | 6/36 |
| 棍棒 | 12 | 1/36 |
| グロック・SKS | 11 | 3/36 |
| クロスボウ | 10 | 6/36 |

素手、固定物への攻撃、回避・非貫通・ダメージ0ではクリティカル用の乱数を使わない。Luaの直接damage効果も全体HPへの被害のみで、武器クリティカルを発生させない。`damage(source, target, amount)` とLuaのdamage/healからbody_partを削除した。

出血段階は時間経過では進まない。毎世界ターンの末尾、各部位の出血1・大出血2・切断4を合算して全体HPを減らす。敵味方共通で、on_damageと死亡処理も実行する。メニューの閲覧では世界ターンを進めない。新しく受けた負傷もそのターン末の計算に含める。

片脚切断は移動速度1/4（1マスに4世界ターン）、両脚切断は1/8（8世界ターン）。敵も同じ間隔で移動し、移動待ちの間も出血は毎ターン計算する。近接攻撃・射撃・装備等の移動以外の行動は通常の一ターン。壁に阻まれた移動では時間を進めない。プレイヤーが長い移動の途中で死亡したら、その時点でリスポーンし、残りの待ち時間を打ち切る。

部位を狙う攻撃操作・切断部位の再生は未実装。healは全体HPのみ回復する。部位の止血は包帯で行う（後述）。

## 左右の手・持ち方と武器補正

左右それぞれに一つのアイテムを装備でき、両手持ちは同じアイテムが両手を占有する。手の装備対象は武器とcommon.tagsにshieldを持つ盾だけ。包帯・食料・工具は装備せず使用する。切断された手への装備は拒否する。切断時に既存装備は所持品・手の枠に残るが使用不可。両手装備は片方の手の切断で使用不可になり、片手対応の武器なら健在な手に持ち替えられる。装備を置き換える際、競合する両手装備は両方の枠から外す。置く・消費完了・削除でも手の枠を更新する。

`movable.dominant_hand` はright/left（省略right）。逆手だけで持った武器は、貫通後に決めた合計被害へ3/4を掛け端数を切り捨てる。両手持ちには逆手補正を掛けない。自動攻撃は最後に装備した使用可能な武器を優先し、手の欠損や耐久不足で使えなければ利き手→逆手を探す。f/rは同じ順序で射撃武器を選ぶ。二刀同時攻撃は行わず、一行動につき一武器で攻撃する。

全武器の `item.weapon.hands` はone（片手専用）/two（両手専用）/either（両対応）の必須値。ナイフone、棍棒either、グロックeither、SKS・クロスボウtwoを仮設定した。

- 両対応の近接武器は `two_hand_pv_bonus`（0〜30、省略0）を両手持ちのPVへ加える。片手には加えない。棍棒は＋1。基礎PVや筋力補正の扱いは従来どおり。
- 両対応の武器では片手時の `one_hand_range_penalty` と `one_hand_accuracy_penalty`（省略0）を設定できる。グロックは射程−2、命中−1。射程6が片手で4になる。射撃対象選択・Luaの攻撃可否・実攻撃に同じ実効射程を使う。
- 所持品wでは、武器のhands・手の欠損を考慮した持ち方だけを表示する。片手専用は右/左、両手専用は両手のみ。解除はその品を装備中の場合だけ表示する。選択中は無料、装備確定・解除は一ターン。不正な装備要求は装備・時間・乱数を変えない。


## AV・DV・PV と能力値

| 値 | 役割 | 初期計算案 |
| --- | --- | --- |
| AV | 装甲。高いほど貫通されにくい | 種類固有の base_av + 装備等の av_bonus |
| DV | 回避。高いほど命中されにくい | 6 + 敏捷修正 + dv_bonus + 装備のDV |
| PV | 貫通。高いほど貫通回数が増える | 武器の base_pv + 筋力による補正（近接のみ） |
| 命中補正 | 命中判定への加算 | 敏捷修正 + accuracy_bonus |

原作でも敏捷は命中・回避、筋力は近接の貫通に関係する。
[原作の近接戦闘](https://wiki.cavesofqud.com/wiki/Melee_combat) を参考にしつつ、
本ゲームの能力値の基準は既存定義に合わせて 8 とする。

```text
筋力修正 = floor((kinryoku - 8) / 2)
敏捷修正 = floor((subayasa - 8) / 2)
近接 PV = max(0, base_pv + min(筋力修正, strength_cap) + 両手持ち時のtwo_hand_pv_bonus)
遠距離 PV = base_pv
```

strength_cap は武器が受け取れる正の筋力補正の上限。負の筋力補正は適用する。
技能による追加補正は初期案では 0 とし、後から独立に追加する。
AV / PV は非負、DV と各種補正は負数も許す。中間計算は符号付き整数で行う。
全防具の部位平均や盾のブロック判定は保留し、当面の AV・DV は個体全体の値とする。

## 1. 命中判定

```text
命中値 = 1d20 + 敏捷修正 + accuracy_bonus - 片手持ち時のone_hand_accuracy_penalty
命中値 > 対象の DV なら命中（同値は失敗）
```

DV と命中値を比べる考え方は [原作の DV 解説](https://wiki.cavesofqud.com/wiki/DV) を参考にする。
本ゲームでは自然の出目 1 は必ず失敗、20 は必ず命中とする。
この自然出目の扱いを近接・遠距離で統一する点は本ゲームの簡略化。
20 でも PV の加算や最低一回の貫通は保証しない。特殊な会心効果は後から検討する。

破壊可能な static は回避しないため命中判定を省き、貫通判定から始める。
地面のように破壊不可の対象は攻撃要求自体を拒否する。

## 2. 貫通判定（Qud を参考にした簡略版）

命中したら PV と AV を比べ、次の手順で貫通回数を決める。

1. 有効 PV を最終 PV に、貫通回数を 0 にする。
2. `1d10 + 有効 PV > AV + 5` を独立に三回判定する。
3. 成功が 0 回なら終了する。
4. 成功が 1～2 回なら貫通回数に 1 を加えて終了する。
5. 三回とも成功なら貫通回数に 1 を加え、有効 PV を 2 減らして手順 2 に戻る。
6. 安全のため十組までで打ち切る。最大貫通回数は 10。

有効 PV は再判定中には負数になってもよく、0 に丸め直さない。
初回から成功がなければ「命中したが非貫通」として被害は 0。
AV をダメージから引く追加の軽減処理は行わない。

三回の判定と継続という骨格を参考にしているが、通常の 1d10 を使い、
PV の減少を最終値へ適用し、回数上限も設けるため原作の確率とは一致しない。
原作と同じ貫通率であると扱わない。

## 3. ダメージ判定

武器の damage は `{ dice, sides, bonus }` で定義する。
例えば `{ dice = 1, sides = 6, bonus = 0 }` は 1d6 を表す。
貫通一回ごとに独立にダイス一組を振り、その合計を被害にする。
一度振った値を貫通回数で掛ける処理にはしない。

```text
一回分 = max(0, dice 個の 1..sides の乱数の合計 + bonus)
被害 = 貫通回数ぶんの「一回分」の合計
```

例：1d6 の攻撃で貫通が二回なら、2 と 5 を振った場合は合計 7 ダメージ。
命中していても貫通が 0 回ならダメージダイスは振らない。
命中・貫通・ダメージの乱数は Rust 側のシード管理された乱数から取り、Lua で振り直さない。
乱数生成にはbracket-libの `RandomNumberGenerator::seeded` を使用する。Gameの複製時も生成器の状態を複製する。以前の独自乱数と出目の列は異なるが、同じ版・シード・操作では再現可能。

## 部位・死亡・破壊

movable の全体HPを `max(0, current_hp - damage)` に更新する。
全体HPが0、または頭・胴体のいずれかが切断されると死亡する。
四肢の切断だけでは死亡しない。プレイヤーのリスポーンでは全体HPと全ての部位の状態を回復する。
static は共通耐久を同じ方法で減らし、0 で破壊とする。

被害を適用後に on_damage を通知し、敵の死亡・固定物の破壊時は on_destroy を一度通知して削除する。プレイヤーは削除せず、所持品・装備を保持してHP等を回復し初期位置（塞がっていれば最寄りの空きマス）へリスポーンする。
生成・削除・配置索引の更新は Rust が行う。木は Lua の on_destroy から木材生成を要求する。
死体・戦利品は定義されている場合だけ生成し、全モンスターへ自動で追加しない。
Lua hook の失敗ではその hook の戻り値を破棄する。すでに確定した元の被害は取り消さない。

## Lua 定義

次の例は schema_version 2 で用いる設定の断片。数値 damage と混在させない。

```lua
-- movable 固有設定内
combat = { base_av = 1, dv_bonus = 0, accuracy_bonus = 0 },
attack = { base_pv = 3, strength_cap = 1,
    damage = { dice = 1, sides = 3, bonus = 0 }, range = 1 },

-- item.weapon 内（近接の例）
base_pv = 4,
strength_cap = 2,
accuracy_bonus = 0,
damage = { dice = 1, sides = 6, bonus = 0 },

-- static 固有設定内
combat = { base_av = 3 },
```

dice は1～20、sides は1～100、bonus は-1000～1000。
base_pv / strength_cap は0～30、base_av は0～100、dv_bonus / accuracy_bonus は-100～100として検証する。
防具のAV・DV加算は実装済み。部位平均は未実装。
既存のナイフ・棍棒・銃などの威力をそのままダイス面数にせず、別途調整する。
`ctx:can_attack` は射程・視線・残弾などの成立条件だけを返し、命中や貫通の乱数は消費しない。

## 部位への包帯と止血

所持品の包帯でEnterを押すと、現在出血していて未処置の部位のみ選べる。出血/大出血/切断による出血を対象にし、健康な部位・止血済み・すでに包帯中の部位は表示しない。選択・中止は時間も包帯も消費しない。部位を確定すると包帯を一個消費して巻き、一ターン進める。装備の必要はない。

同梱Luaは `item.use = { kind = "bandage", amount = 100 }`。amountは処置開始から止血までの世界ターン数。処置中も通常の出血被害を与え、100ターン目のターン末の出血計算後に止血して巻いた包帯を除去する。部位の負傷段階と止血済みフラグを分離し、止血しても切断状態・能力制限・負傷段階は戻さない。自分のプロパティに包帯中・残りターン、観察には包帯中/止血済みを表示する。

処置中のクリティカルは部位の段階を通常どおり一段階進める。包帯の完了時刻は変更しない。止血後の未切断部位へクリティカルが入ると、保持した段階から一段階進み、止血済みを解除して再出血する。切断済み部位は従来どおりクリティカルの抽選から除く。死亡した敵の処置は個体とともに消え、プレイヤーのリスポーン時も処置と止血済み状態をクリアする。

所持品w→数字で武器・盾を登録と装備し、通常画面の同じ数字で持ち替える。防具はw一回で直接着脱する。
