# 食料・栄養ルール

タンパク質 `protein`、炭水化物 `carbohydrate`、ビタミン `vitamin` は可動Entityごとに保持する。
三種類とも小数で保持し、初期値50、上限100、下限0。独立した満腹度は廃止し、炭水化物がその役割を担う。
画面の残量は整数に切り上げる。内部の残量が正なら1以上、使い切ると0と表示する。
水分 `hydration` は別に保持し、既存どおり10世界ターンごとに1低下する。

## 摂取

食品一個の栄養はLuaの `item.nutrition` に三種類全てを指定する。値はゲーム用のポイント。
食品の定義値はu32整数を検証し、個体の残量へ加算するとき100を上限とする。
`Nutrition::default()` は個体の0/0/0、`Nutrition::initial()` は個体の50/50/50を表す。

```lua
item = {
    nutrition = {protein=8, carbohydrate=45, vitamin=2},
    use = {kind="nutrition"},
}
```

パンはタンパク質8・炭水化物45・ビタミン2、ビタミン剤はビタミン10。
生肉など炭水化物0の食品も、タンパク質が不足していれば食べられる。
食品が増やす栄養のどれか一つでも不足していれば使用可能。
増やせる栄養が全て100なら、個数・時間・栄養・副作用を一切消費/適用しない。
ビタミン剤もビタミン100では使わない。

食品は `gain_nutrition` と `consume_item` を一つの効果列で返し、一個分だけ加算する。
飲料は `restore_need`（hydrationのみ）、`gain_nutrition`、`consume_item` を返す。
水分が最大なら飲料は使わない。途中で失敗した場合は全効果と乱数を巻き戻す。
受け付けた飲食・栄養剤使用は一個と一世界ターンを消費する。
腐肉・汚染水の直接被害3は維持するが、そのターンに自然回復の条件を満たせばHP1も回復する。

## 時間経過による消費

炭水化物は生存中の可動Entityごとに、世界ターン1回で消費点1、成立した攻撃一回で追加1を累計し、20点ごとに0.25減らす。端数は次のターンへ持ち越す。通常20ターン、攻撃だけなら10ターンで0.25減る。近接・射撃・投擲は外れ/被害なしでも加算し、射程外・弾切れなど攻撃が成立しない場合は追加しない。
ビタミンは世界ターン20・40・60…の末尾で0.25減る。どちらも0では止まり、減らせなかった分を後から請求しない。
移動・待機・攻撃・飲食など、時間を進めた行動が対象。閲覧だけでは減らない。
炭水化物の移動一マスごとの消費は廃止。脚切断による4/8ターンの移動も経過した世界ターン数に従い、移動自体の追加消費はない。
栄養消費後に病気の判定・経過時間を更新するため、そのターンにビタミンが0になれば悪化側の経過を開始する。
現段階で炭水化物0による移動禁止・飢餓ダメージは加えない。

## 走行とスタミナ

v（Velocity）で走行／歩行を無料で切り替える。HP・能力値の体力とは別にスタミナを持ち、初期値・上限100。走行は1マスにつき5を使い、2マスで1世界ターン進む（最初の一歩で1ターン、次の一歩は0ターン）。切り替えでは移動時間の端数をリセットしない。失敗移動・攻撃では走行スタミナを使わず、攻撃は通常の1ターン。脚切断中は走れない。
スタミナ5未満で走行を自動解除。走行ON中は待機しても回復しない。走行OFF中は世界ターンごとに最大5回復し、実回復20ごとに炭水化物0.25を追加消費する。端数を保持し、満タン・閲覧では回復消費なし。炭水化物0では回復停止。通常の時間消費・攻撃消費とは別に扱う。
死亡復帰でスタミナ100・走行OFF・移動時間と回復消費の端数0へ戻す。肺炎の移動被害は走行でも実際に進めた世界ターンで数える。

## 自然回復

正常でタンパク質が残っていれば、生存中の可動Entityの全体HPを毎世界ターン1回復し、実際にHP1が増えるごとにタンパク質0.25を消費する。最大HPでは回復も消費もしない。
タンパク質0または風邪・肺炎では自然回復を止める。HP0や頭/胴体切断による死亡を自然回復で取り消さない。
回復は敵の行動・継続出血・包帯完了の処理後に行う。メニュー閲覧だけでは回復しない。
出血でHPを1失うターンに自然回復でHPを1得ると、ターン後のHPは同じになる。HUDのHP欄に毎ターンの出血ダメージを表示する。
部位の負傷・切断は治さない。注射器などの直接回復効果は既存どおり別に扱う。
注射器などの直接回復は風邪・肺炎中も使え、タンパク質を消費しない。

## ビタミンと風邪・肺炎

病状は正常 → `cold`（風邪）→ `pneumonia`（肺炎）の三段階。同時に重複しない。
ビタミン0の間は、正常・風邪で100世界ターンを過ごすごとに1/6で一段階悪化する。肺炎より先の段階はない。
ビタミンが0より大きい間は悪化させず、風邪・肺炎で100世界ターンを過ごすごとに1/2で一段階回復する（肺炎→風邪→正常）。ビタミンの摂取だけで即座には治らない。
正常かつビタミンが0より大きければ発症判定しない。ビタミン0での自然治癒はない。
ビタミンが0か正の値かの切替で反対側の経過時間をリセットする。病状が変わったときも経過時間をリセットし、次の段階へは新たな100ターンを必要とする。判定失敗でも次の判定まで100ターン待つ。回復判定自体ではビタミン・タンパク質を消費しない。
風邪・肺炎では自然回復を止めるが、食品・ビタミン剤・注射器などの使用は可能。病状をHUD・プロパティ・可視対象の調査に表示する。

肺炎では、成功した移動に使うターンを累計し、10ターンごとに全体HP1を失う。一歩1ターン、脚切断で4/8ターンかかる一歩は4/8を加算する。移動失敗・移動待ち・待機・攻撃・メニュー閲覧は加算しない。肺炎になったとき/肺炎が治ったときは移動累計をリセットする。
この減少だけではHP1より下がらず、死亡済みのHP0を復活させない。戦闘・出血・食品の被害などは通常どおり死亡し得る。
病気判定は戦闘とは別のシード付き乱数を使い、複製・巻き戻しでも維持する。

## 復帰・確認

死亡からの復帰では三栄養を各50へ戻し、炭水化物の消費点も0へ戻す。風邪・肺炎などの状態と病気/移動の経過時間も解除する。
満腹度の型・Luaのsatiety・表示は除去し、needsはhydrationのみを受け付ける。
Rust/Luaテストで上限・摂取・移動・回復・風邪を確認する。長期バランスと実GUIは未確認。
自動腐敗・調理・保存復元は未実装。
