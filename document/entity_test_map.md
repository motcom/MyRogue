# Entityテストマップ

全83定義を置いた76×38マスの専用マップ。全試験用アイテムと開始位置を左上の倉庫へ集めている。

```sh
cargo run
```

このマップが既定で起動する。起動済みの場合はCtrl+Qで終了して再起動する。
ウィンドウ表示は `--windowed`、無音は `--mute` を追加する。
GUIなしの確認は `--check-data` または `--simulate 100`。従来の通常マップは `--normal-map` で選べる。

## 左上の安全な倉庫

開始・死亡復帰は `(4,4)`。石壁はx=1〜27・y=1〜20、東の出口は `(27,19)`。
全種類の試験用アイテムが倉庫内にある。敵を出した後も扉を閉めて準備する。
敵の全個室を開放し、銃を持つ敵が扉の外にいても、閉じた倉庫内で100ターン準備できることをテストしている。

| 区画 | 配置（左から順） |
| --- | --- |
| 近接武器 | y=3、x=3,6,9,12,15,18,21,24。ナイフ・棍棒・ショートソード・ロングソード・バスタードソード・メイス・槍・大鉈 |
| 射撃武器 | y=6、x=3,7,11,15,19。グロック・クロスボウ・SKS・AK・M16 |
| 弾薬・投擲 | y=9、x=3:拳銃弾50、7:ボルト20、11:ライフル弾50、15:爆発手榴弾5、19:閃光手榴弾5 |
| 回復・栄養剤 | y=11、x=3,7,11。包帯・注射器・ビタミン剤を各3個 |
| 食料・飲料 | y=14、x=3から21まで2マス間隔。りんご・生肉・焼肉・腐肉・パン・人参・キャベツ・ミネラルウォーター・汚染水・清潔な水を各3個 |
| 製作 | 作業台(4,18)、木材5個(5,18)、ハンマー(7,18) |
| 装備・箱 | 革の鎧(11,18)、盾(15,18)、宝箱(23,18) |

足元でg、iで所持品。武器はw→持ち方→数字で登録・装備する。必要な試験品だけを拾う。

- 槍など射程2以上の近接武器はf→hjklyubn/矢印で敵選択→Enter/fで攻撃。隣接敵は通常画面の方向入力でも攻撃できる。
- 射撃武器はrで装填後、fで敵を選ぶ。装填成功時にはリロード音が鳴る。
- 回復品・食品・飲料・投擲品はEnter、またはw→数字で登録して使う。手榴弾はマス指定。
- 三栄養は初期50・上限100。食品が補う栄養が全て100なら使わない。炭水化物は通常20ターンで0.25低下し、攻撃では消費点が倍になる。ビタミンは20世界ターンで0.25、水分は10世界ターンで1低下する。
- 正常でタンパク質があれば毎ターンHP1回復し、タンパク質0.25を消費（満タン時は消費なし、風邪・肺炎中は停止）。注射器はHP低下時、包帯は出血部位に使う。腐肉・汚染水の直接被害3にも同じターンの自然回復が適用される。
- 木材とナイフを持ち、(4,17)か(5,18)でp→Enterを3回押すと棍棒を製作。完成品は足元。ハンマーは切削工具の代用にはならない。
- 宝箱は隣からe→方向→開く。Spaceで中身を選びEnterで取得する。

出口は `(26,19)` からe→lで開く。初期位置からx=2の通路を南へ進めば作業台を避けて出口へ向かえる。
倉庫と試験室の間のx=28〜29は縦通路。`;` で座標・Entity名・説明を確認できる。

## 左下の固定物・地形

固定物はy=21、x=3から27まで3マス間隔。
広葉樹・針葉樹・生垣・柵・木の壁・椅子・テーブル・ランプ・池の順。
近接武器を装備し隣からtで破壊を試す。池は通行不可、ランプは表示のみ。

野原はx=3〜7・y=27〜29で経路コスト2、荒地はx=11〜15・y=27〜29で4、他の床は道で1。

## 制作の試作（2026-11-16）

(4,17)に立ち、ナイフを所持してpを開く。作業台(4,18)と制作ストレージ(5,17)を利用できる。収納には木材・鉄材・布・革・糸・木炭・木柄・生肉・汚染水と工具7種が入っており、取り出す操作なしで制作に使える。y=17には追加した工具・材料の単体見本も配置した。12レシピの必要量・道具レベル・推奨スキル・成功率を確認してEnterで作業する。推奨未達でも挑戦でき、実際の成否は確率で変わる。
