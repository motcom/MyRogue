#### 追加するグールの設計

以下の8種類はLua定義・固有行動・東部のマップ配置を実装済み。能力値と行動速度は仮設定。

| 名前 | 特徴・行動 | 対処法 |
| --- | --- | --- |
| グール・ランナー | 痩せた高速型。装甲は薄く、素早く接近する | 接近前に射撃する。脚の切断で移動速度を落とす |
| グール・ブッチャー | 両手の大鉈を使う。高PV・クリティカル重視で、動きは遅い | 距離を保つ。腕を切断して両手武器を使用不能にする |
| グール・ガード | 盾と棍棒を持つ。装甲が硬く、通路を塞ぐ | 高PVの武器で貫く |
| グール・ハウラー | 敵を発見すると叫び、周囲のグールを呼び寄せる | 仲間が集まる前に優先して倒す |
| グール・スカベンジャー | 落ちている武器や弾薬を拾って使う。装備次第で強さが変わる | 装備を観察し、危険な武器を拾わせない |
| グール・ストーカー | 建物や遮蔽物の周辺で待ち伏せし、近距離から襲う | 扉を開ける前後に周囲を調べる |
| グール・ブルート | 巨体でHP・筋力が高い。低DVで攻撃は当てやすい | 出血を与え、距離を取る |
| グール・ライフルマン | 両手のライフルで遠距離攻撃する。接近されると弱い | 射線を遮って接近する |






## 固有行動の実装（2026-11-15）

Luaのon_turnが `ghoul_turn` とbehavior名を返し、Rustの通常の移動・装備・戦闘検査へ接続する。

- ランナーは一ターンで最大2歩接近し、攻撃は一回まで。脚切断の移動待ちを優先する。
- ブッチャーは偶数ターンだけ行動し、両手の大鉈（PV8・クリティカル9）を使う。
- ガードは基礎AV4に盾AV2を加算。盾を持つ腕が切断されると盾の防御を失う。
- ハウラーは発見時に一行動を使って叫ぶ。半径8内の同陣営へ最後に見た位置を6ターン通知し、既存3種のグールもその位置へ向かう。遮蔽物越しでも音は届く。通知は現在の敵位置を追跡しない。
- スカベンジャーは武器未所持なら視線内の武器へ向かい、拾得→装備する。装備した銃の弾薬も拾い、通常の装填・射撃を行う。拾得・装備は一行動、容量不足なら取得せず戦闘へ戻る。
- ストーカーは距離3以内で敵を見つけるまで配置位置に待機する。透明化はしない。
- ブルートはHP120・筋力18・敏捷3。近接と継続出血は既存のルールに従う。
- ライフルマンはSKSと弾薬20発、HP32・筋力6。装填してから射撃する。

各行動はRust/Lua統合テストで確認。実GUIとゲームバランスは未確認。
