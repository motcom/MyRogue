# 固定物

野原・道・荒地・池は[map_entity](map_entity.md)へ分離済み。staticは下記の固定物11種。木・針葉樹はplacement=spawn、それ以外はmap_gen。spawnする破壊可能物にはdestroyed_mapを指定する。

隣接する破壊可能な固定物は `s` を押してから方向を指定して攻撃できる。

### 移動コスト

地面はLua定義の `map.movement_cost`、固定物は `static.movement_cost` で、そのEntityがあるマスに入る経路コストを設定する。

```lua
map = {
    movement_cost = 2.0,
    spawns = {},
},
```

- 同梱設定は道 `1.0`、野原 `2.0`。荒地は `4.0`。
- 省略時は `1.0`。指定範囲は `0.01` 以上 `1000` 以下の有限数。小数も使える。
- `2.0` は通常の倍の経路コスト、`0.5` は半分。経路探索は歩数でなく合計コストが小さい経路を選ぶ。
- 地面は各セル一つで置き換える。移動先にあるmap/static Entityのうち、描画layerが最大のものを採用。同layerならEntity IDが大きいものを採用する。道を設定した場合は以前の野原を置き換える。固定Entityがないマスは `1.0`。
- `common.collision.movement = true` のマスには、コストにかかわらず入れない。通行の可否とコストは別に設定する。
- 縦横・斜めとも移動先のコストを一回加算する。プレイヤー・敵で同じ地形コストを使う。
- 現時点では経路選択用。実際の移動は従来どおり一回一ターンで、コストによる速度差は付けない。
- Luaの `ctx:movement_cost({x=3, y=4, z=0})` でそのマスのコストを取得できる。マップ外は `nil`。この問い合わせは通行可否を判定せず、壁のあるマスでも値を返す。

値は起動時に読み込む。変更後はゲームを再起動する。
### 扉

木の扉はStatic。Luaのinteractions / on_interactで開閉を登録し、個体ごとの通行・視線・表示文字を切り替える。[インタラクト仕様](../interactions.md)を参照。


## 固定物の追加（2026-11-15）

一覧の固定物は全て定義・展示配置済み。既存の「木」を広葉樹として扱う。
荒地は通行可能で経路コスト4。テーブル・椅子・柵は通行を遮るが視線は通す。
木の壁・針葉樹・生垣は通行と視線を遮る。木製の障害物は破壊時に木材を生成する。
テーブルは作業面と万力を提供する仮設定。ランプは通行可能な表示用固定物で、光源による視野拡張は実装しない。
