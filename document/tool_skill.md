# 道具の機能：初期設計案

自分のゲーム用に、CDDA の tool qualities を参考に整理した案。
キャラクターの技能とは分けて、道具が可能にする作業を表す。機能の有無と一部設備の判定はゲームへ接続済み。機能ごとのレベルと制作要求の判定も試作実装へ接続済み。具体的なレベル値は調整対象。
制作ルールの正本は [production/README.md](production/README.md)。2026-11-16のユーザー指定により、機能の有無だけを判定する旧案から、機能ごとにレベルを持つ方針へ変更した。

## 道具の機能は 13 種類

| 機能 | できる作業の例 | 道具の例 |
| --- | --- | --- |
| 切断 | 布・ロープ・皮などを切る | ナイフ、はさみ |
| 伐採・製材 | 木を切り倒す、木材を切り出す | 斧、のこぎり |
| 打撃 | 釘打ち、部品の打ち込み | ハンマー |
| 穴あけ | 木や皮などに穴をあける | ドリル、錐 |
| 締結 | ねじ・ボルトを締める、外す | ドライバー、レンチ |
| こじ開け | 板を剥がす、釘を抜く、障害物をこじ開ける | バール |
| 掘削 | 土を掘る、穴を埋める | シャベル |
| 裁縫 | 衣類・袋を作る、直す | 針、裁縫セット |
| 調理 | 食材を加熱する、水を煮沸する | 鍋、調理器具 |
| 解体 | 獲物から肉や皮を取り出す | ナイフ、解体用具 |
| 金属切断 | 金属棒や板を切り分ける | 金属用のこぎり、切断機 |
| 研削 | 金属の形を整える、刃を研ぐ | やすり、砥石、研削盤 |
| 溶接 | 金属部品を接合する | 溶接機 |

## 作業台・設備

金属加工と作業台は実装対象に含める。次の 4 種類を初期案とする。
道具の機能とは別に、作業する場所が提供する条件として扱う。

| 設備条件 | 役割 | 設備の例 |
| --- | --- | --- |
| 作業面 | 部品を置いて加工・組み立てする | 作業台 |
| 固定 | 加工する材料を動かないように保持する | 万力、万力付き作業台 |
| 金床 | 鍛造時に材料を支える | 金床 |
| 鍛造用加熱 | 金属を鍛造に必要な温度まで加熱する | 鍛冶炉 |

- 一つの設備が複数の条件を提供できる。例：万力付き作業台は「作業面」「固定」。
- プレイヤーと同じマスまたは隣接する上下左右のマスにあり、間が遮られていない設備を利用する。現行の棍棒制作では作業面の判定を接続済み。
- 鍛造は「打撃」の道具と「金床」「鍛造用加熱」の組み合わせで表す。
- 調理用の熱源と鍛造用の加熱は区別する。焚き火だけで鍛造できる扱いにはしない。
- 電力・燃料・溶接材料などの消費量、加工可能な金属の範囲は今後決める。

## 金属加工の作業例

以下はゲーム内レシピの設計例。出力個数・所要時間・必要技能は未決定。

| 作業 | 道具の機能 | 設備条件 | 材料・消費資源の例 |
| --- | --- | --- | --- |
| 金属棒を切り分ける | 金属切断 | 作業面、固定 | 金属棒。動力工具なら電力なども必要 |
| 刃物の形を整える | 研削 | 作業面、固定 | 加工途中の刃。動力工具なら電力なども必要 |
| 刃物を鍛える | 打撃 | 金床、鍛造用加熱 | 鍛造可能な金属、炉の燃料など |
| 金属枠を組み立てる | 溶接 | 作業面、固定 | 金属部品、電力・溶接材料など |

初期案の金属加工は切断・鍛造・研削・溶接までとし、溶解・鋳造や熱処理の細分化は保留する。

## 扱い方

- 一つの道具が複数の機能を持てる。例：ナイフは「切断」「解体」。
- 各機能にレベルを持たせる。例：穴あけLv2を要求するレシピには、穴あけLv2以上の道具が必須。Lv1を複数用意してもLv2にはならず、別機能のレベルやキャラクターの技能でも代用しない。
- 一つの道具が複数機能を持つ場合、各機能のレベルは別々に設定する。例：切断Lv1・穴あけLv2。
- 要求機能レベルは制作可否に使い、制作スキルは成否と完成品の出来に使う。道具の機能レベルと完成品の＋／−は別の値。
- 材料・燃料・消耗品などの条件は作業側で要求する。例：裁縫には糸、調理には熱源と必要な容器を要求する。
- 同じ機能でも全素材を扱えるとは限らない。必要に応じて作業ごとに素材への対応を定義する。例：木の製材ができても金属切断はできない。
- レベルや対応素材の具体値はレシピと合わせて決める。制作で要求を上回るレベルを用意した場合の補正は、制作ルール案を参照する。

## 必要になるまで保留

- 専門作業：開錠、釣り、化学、医療など。それぞれの遊びを追加する段階で検討する。
- 追加設備・環境：持ち上げ、遮光など。関連する作業を追加する段階で検討する。
- 個別用途：筆記、喫煙、清掃、銃の練習など。初期の共通機能一覧には含めない。
