# 制作ルール・初期案

制作（コード中の crafting／既存資料の「製作」）のルールをここにまとめる。
2026-11-16改訂。材料・道具の必須化、道具の機能レベル、スキルによる成否と出来の変化はユーザー指定の方針。以下は設計全体の案。今回の試作で接続した範囲とLuaの編集方法は [lua.md](lua.md) を参照。設計案と実装の差がある場合は同ファイルの「今回接続した範囲」を優先する。

## 1. 制作の基本

制作には必ず材料と道具が必要。作れる対象は、用意した材料と道具の機能・レベルで決まる。
制作スキルは挑戦を禁止する条件にはせず、成功率と完成品の出来に影響する。
レシピの推奨スキルに届かなくても成功することがあり、届いていても失敗や不出来な品になる可能性がある。

1. 材料・道具・必要設備などの必須条件を確認する。
2. スキル・道具・材料から成功率と出来の傾向を示す。
3. 作業時間を使い、完了時に成功か失敗かを判定する。
4. 成功した場合は出来を判定し、出来に応じた称号と＋／−を付ける。

「制作不可」「制作に失敗」「不出来だが完成」を区別する。

## 2. 必須条件

| 条件 | 満たす必要があること | 不可になる例 |
| --- | --- | --- |
| 材料 | 指定された材料枠すべての種類・状態・数量 | 木材不足、刃物用の鋼材に木材を指定 |
| 道具 | 必要な機能とその要求レベル、使用可能な状態 | 穴あけLv2が必要なのにLv1しかない |
| 設備 | レシピで指定された設備と利用範囲 | 金床や鍛造用加熱がない |
| 消費資源 | 指定された燃料・電力・糸などの数量 | 溶接機はあるが電力がない |
| 作業者 | 生存し、必要な手を使える状態 | 道具を使える手がない |

すべてのレシピに材料枠と道具の要求を一つ以上設定する。素手だけ・材料なしの制作は設けない。
スキル不足は制作不可の理由にしない。高いスキルでも道具や材料の不足は補えない。
レシピは最初から一覧で確認でき、不足理由を表示する案とする。習得による解禁は保留。

材料と道具は所持品・足元・隣接8マス・その範囲のストレージ内から使う（ユーザー指定）。閉じた収納も制作時に取り出して使える。設備も同じマスか隣接8マスにある、間が遮られていないものを使う。
材料を二重計上したり、同じ品を材料と道具の両方に使ったりしない。

## 3. 道具の機能レベル

機能の種類は[道具の機能案](../tool_skill.md)の13区分を使い、それぞれにレベルを設ける。
例：切断Lv1、穴あけLv2、打撃Lv3。一つの道具が複数の機能を異なるレベルで持ってもよい。
レベルはその機能で可能な加工の程度であり、キャラクターの制作スキルや完成品の出来とは別の値。

| 機能レベルの例 | 加工能力の目安 | 穴あけの例（仮） |
| --- | --- | --- |
| Lv1 | 簡単な加工 | 薄い皮や柔らかい木に穴をあける錐 |
| Lv2 | 一般的な加工 | 木柄や加工可能な薄板に使う手回しドリル |
| Lv3 | 高度な加工 | 対応素材へ精度を要する穴をあける据置ドリル |

上表はゲーム用の例。対応できる材質・厚さはレシピ側でも指定し、レベルだけで何でも加工できる扱いにはしない。
レベルの上限はまだ決めず、初期レシピはLv1〜3で試す。

- 要求が穴あけLv2なら、Lv2以上の穴あけ機能を持つ使用可能な道具が必要。
- 穴あけLv1を二つ持ってもLv2にはならない。
- 切断Lv3でも穴あけLv2の代わりにはならない。
- 切断Lv1と穴あけLv2を同時に要求する場合は、両方を満たす。一つの複合道具でも複数の道具でもよい。
- 同じ機能の候補を複数持つ場合は選んだ道具のレベルを使い、足し合わせない。
- より高いレベルの道具には補正を付ける案とし、余裕の最も少ない要求を基準にする。

```text
各要求の道具の余裕 = 選んだ道具の機能レベル − レシピの要求レベル
道具補正 = 5 × 各要求の余裕の最小値（最大＋10）
```

要求レベル未満なら補正計算の前に制作不可。
設備は作業面・固定・金床・鍛造用加熱を基本とし、必須設備がそろうだけでは補正を付けない。
調理用の熱源と鍛造用加熱も分ける。

## 4. 材料

レシピは材料枠ごとに使える材料・必要量・材料補正を指定する。
単に「金属」という材質が一致するだけでは使用できない。刃物用の鋼材、柄に使える木材などを明記する。

| 材料 | 可否 | 補正の仮値 |
| --- | --- | --- |
| 種類・状態が不適切、数量不足 | 不可 | 計算しない |
| レシピが認める劣化材・代用材 | 可 | −10 |
| 標準材料 | 可 | 0 |
| 加工しやすい良好な材料 | 可 | ＋10 |

複数の材料枠や異なる状態の材料を使う場合は最も低い補正を採用する。
良い材料を必須とする指定と、良い材料なら補正が付く指定は分ける。
材料補正は成功率と出来の両方へ反映する案とする。

## 5. 制作スキル

既存の木工 `wood_craft`、金属加工 `metal_craft`、電子工作 `denshi_craft`、裁縫 `saihou`、調理 `cooking` を使う。
初期レシピはスキル0〜5を目安に調整するが、この案で既存スキルの上限は変更しない。

レシピには「推奨スキル」を設定する。これは制作禁止の境界ではなく、難易度の基準。
複数のスキルを使う場合は、各スキルと推奨値との差の最小値を採用する。
木工が得意でも金属加工が苦手なら、その不足がメイス制作の難しさに残る。

```text
スキル差 = 現在スキル − レシピの推奨スキル
複数スキルの場合のスキル差 = 各スキル差の最小値
```

すべての初期レシピに関係するスキルと推奨値を設定し、推奨0の簡単な制作も用意する。

## 6. 成功と失敗

仮の成功率は次の式とする。補正はパーセントポイントで加減する。

```text
成功率 = 60 + 10 × スキル差 + 道具補正 + 材料補正
最終成功率 = 成功率を5〜100%に収めた値
```

必須条件がそろっている場合に限り、低スキルでも成功率5%は残す。
成功判定は完了時に一度だけ1〜100の整数を抽選し、成功率以下なら成功。100%なら失敗しないが、出来は別に判定する。

| 例 | スキル／推奨 | 道具補正 | 材料補正 | 成功率 |
| --- | --- | --- | --- | --- |
| 棍棒を初心者が削る | 木工0／0 | 0 | 0 | 60% |
| 同じ棍棒を経験者が削る | 木工2／0 | 0 | 0 | 80% |
| メイスに未熟な状態で挑戦 | 金属加工0／3 | 0 | 0 | 30% |
| 推奨より少し低い腕でメイスに挑戦 | 金属加工2／3 | 0 | 0 | 50% |
| メイスの推奨に到達 | 金属加工3／3 | 0 | 0 | 60% |
| 道具と材料を改善してメイスに挑戦 | 金属加工2／3 | ＋10 | ＋10 | 70% |

表にない材料量・道具レベル・設備などが満たされ、複数スキルでは表の分野が最も低いスキル差になる前提。
道具不足で制作不可の場合に、この成功率を表示して挑戦させない。

## 7. 出来具合と追加称号

完成品が得られたことを「成功」、その性能段階を「出来」と呼び分ける。
不出来な完成品も成功に含め、失敗は完成品を得られない結果とする。

汎用の追加称号として次の6段階を提案する。標準品はユーザー指定により称号も＋0も表示せず、元の品名だけで表示する。「標準」は設計上の区分名であり、名前には付けない。

| 出来の段階 | 称号案 | 名前の表示例 | 意味 |
| --- | --- | --- | --- |
| −2 | 粗悪な | 粗悪なメイス −2 | 使えるが、欠点が大きい |
| −1 | 不出来な | 不出来なメイス −1 | 標準に届かない仕上がり |
| 0 | なし | メイス | 通常の仕上がり（設計上は標準） |
| ＋1 | 良質な | 良質なメイス ＋1 | 丁寧で良好な仕上がり |
| ＋2 | 見事な | 見事なメイス ＋2 | 高い技量が表れた品 |
| ＋3 | 傑作の | 傑作のメイス ＋3 | 制作者を代表する出来 |

「粗悪な → 不出来な → 標準 → 良質な → 見事な → 傑作の」を共通表記の第一候補にする。
「精巧な」は食品・包帯などに合いにくいため共通称号には使わず、将来の分野別表記の候補に残す。
失敗結果に−3などの完成品称号は付けない。

### 出来の判定案

成功した場合だけ、成否判定とは別の1〜100を一度抽選する。

```text
出来点 = 1d100 + 10 × スキル差 + 道具補正 + 材料補正
```

| 出来点 | 結果 |
| --- | --- |
| 10以下 | 粗悪な −2 |
| 11〜30 | 不出来な −1 |
| 31〜75 | 標準 |
| 76〜90 | 良質な ＋1 |
| 91〜100 | 見事な ＋2 |
| 101以上 | 傑作の ＋3 |

推奨と同じ腕・標準道具・標準材料なら、完成した品の内訳は粗悪10%・不出来20%・標準45%・良質15%・見事10%・傑作0%。
これは成功後の条件付き割合であり、制作全体の割合ではない。
スキルが上がるほど失敗や不出来が減り、傑作が生まれる範囲が広がる。推奨未満でも道具・材料がよければ上等な品ができる余地がある。
傑作が出やすくなりすぎる場合は、この境界やスキル補正を調整する。

### ＋／−を何に反映するか

出来は名前だけでなく、その品の主要な性能へ反映する。ただし全性能へ一律に加算しない。

- 武器：第一案はダメージの固定値に出来の段階を加減。棍棒＋1なら `1d2+5`。貫通・射程は変えず、ダメージ下限は既存処理に従う。
- 防具：耐久性への補正を候補とする。防御値は1点の影響が大きいため、＋1をそのまま防御＋1にしない。
- 道具：耐久性などへ反映する案。完成品の＋1を穴あけLv＋1と同一視せず、レシピ要求を越える加工能力は自動付与しない。
- 食品・薬品・包帯：栄養量・回復量・処置時間など、対象ごとに補正先を一つ決める。低品質だけを理由に腐敗や毒を追加しない。
- 材料：品質段階を材料補正へどう変換するかは別途決める。制作の繰り返しで補正が無制限に積み上がる扱いにはしない。

武器以外の具体的な補正率は未確定。各品の効果が決まってから品質付き出力を有効にする。
同じ種類でも出来の違う品は別スタックとし、まとめて通常品に戻したり平均したりしない。

## 8. 時間・中断・材料消費

作業時間はレシピごとの固定値とし、1回の作業で1世界ターンを使う。敵・栄養・出血も進む。
開始時に材料・道具・設備とスキル値を確定し、成功率・出来の分布を決める。
作業直前に必須条件を再検査し、満たさなくなれば停止する。確認失敗では時間を使わない。

- Escで画面を閉じた場合は進捗を保持。条件を戻せば再開できる。
- 選んだ品・設備を変更する場合は進捗と判定条件をリセットする。
- 明示的な中止では進捗を失う。初期案では完了まで材料・資源を消費しない。
- 成功時は出来にかかわらず材料を全量消費する。完成品は所持できる分をインベントリへ入れ、重量・容量・長さの制限で入らない分を足元に置く。
- 失敗時は完成品なし。各材料枠の必要量の半分を切り上げて失う案を継続する。必要量1なら1個失う。
- 指定された燃料・電力は成功・失敗とも規定量を完了時に消費する。
- 完了した成否と出来は確定し、画面を開き直して再抽選しない。失敗後の再挑戦は新規制作として必要な時間と材料を用意する。

消費・生成のエラーは制作失敗とは分け、材料と進捗を失わないようにする。将来の保存でも結果の再抽選を防ぐ。
途中消費・道具の摩耗は今回の案では保留する。

## 9. レシピ例

以下は設計時のレシピ例。機能レベル・推奨スキル・出来の判定は試作へ接続済みだが、実際の材料・時間・設備はLuaレシピを参照する。

| 完成品 | 必須材料 | 必須道具の機能 | 設備 | 推奨スキル | 時間 |
| --- | --- | --- | --- | --- | --- |
| 棍棒1 | 木材1 | 切断Lv1 | 作業面 | 木工0 | 3ターン |
| 包帯2 | 清潔な布1（新規材料案） | 切断Lv1 | 不要 | 裁縫0 | 2ターン |
| 木柄1（新規品案） | 木材1 | 切断Lv1 | 作業面 | 木工1 | 4ターン |
| 穴あき木柄1（新規品案） | 木柄1 | 穴あけLv2 | 作業面・固定 | 木工2 | 3ターン |
| メイス1 | 木柄1・加工可能な鉄材2（新規材料案） | 打撃Lv2 | 作業面・金床・鍛造用加熱 | 木工0・金属加工3 | 12ターン |

メイスの燃料の種類・単位・必要量は未決定。実装前に必ず設定する。
素材への適合、包帯などの出来による効果、各材料枠の許可一覧も追加時に定める。
複数個を一度に作る場合、初期案は制作1回につき出来を一度判定し、同じ出来でまとめて出力する。

## 10. 制作画面の表示案

必要な材料と数量、道具機能の要求レベルと現在値、設備、推奨スキルと現在値、成功率、出来の見込み、所要時間、失敗時損失を表示する。
内部IDは表示せず、不足理由を名前で示す。

```text
穴あき木柄 ×1
材料：木柄 1/1
道具：穴あけLv2が必要 / 所持道具は穴あけLv1
設備：作業台・固定あり
木工：現在1 / 推奨2
制作不可：穴あけLv2以上の道具が必要
```

道具を替えて必須条件がそろえば、スキル不足でも次のように表示する。

```text
穴あき木柄 ×1
木工：現在1 / 推奨2
成功率50% / 作業3ターン
完成時の出来：粗悪20%・不出来20%・標準45%・良質15%・見事0%・傑作0%
失敗時：木柄1を失う
```

後者は道具の余裕・材料補正とも0の例。出来の割合は完成した場合の内訳として表示する。

## 11. 実装との区別・次に決めること

現行の試作はLuaレシピ12件。道具・材料・周辺/収納の検索、機能レベル、成否と出来、品質付き武器/耐久品まで接続した。
[実装と編集方法](lua.md)に参照先と制限をまとめる。前節のレシピ表は設計例であり、実際に利用できるレシピはLua定義を正本とする。
消耗品の品質効果、技能成長、汎用の資源メーター消費、NPC向け制作APIなどは未実装。

次に手直しする項目：

1. 出来の共通称号と6段階の数。
2. 成功率・出来点の補正と境界。傑作の希少性、未熟な制作の扱い。
3. 品目別の＋／−の効果と、材料品質から補正への変換。
4. レシピごとの要求機能レベル・推奨スキル・燃料・材料の許可一覧。
5. 失敗時に失う材料の量、制作経験によるスキル成長。

能力値・負傷・病状による追加補正、時間短縮、レシピ習得は後の段階で検討する。
