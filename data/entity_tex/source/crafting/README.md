# 制作アイテムの専用原画

2026-11-16、内蔵 `image_gen` で14対象を個別に生成した。CLI/APIフォールバックは使用していない。
生成画像の透明背景を保持して、このディレクトリへコピーした。

- `prompts.json`：共通プロンプト＋対象別の指示。連結すると実際に渡したプロンプトになる。
- `recipe.json`：Entity IDと個別原画の対応。
- 各PNG：生成された個別原画。実行時は直接使わず、取り込み後の `../../item/item.*.png` を使う。
- `contact32.png`：表示用32×32 PNGを並べた派生見本。原画としては使わない。

共通指示は、荒廃世界の道具・材料、32×32を想定したピクセルアート、透明背景、読みやすい輪郭、Ash & Rust 32色、文字・床・影なし。
原画には指定外の色や中間アルファが含まれうるため、取り込みで必ずパレットと二値アルファに正規化する。

```sh
python3 tools/import_entity_textures.py --only-crafting
```

縦横比を保持して透明な正方形へ収め、最近傍で32×32へ取り込む。16×16経由の拡大はしない。
原画・プロンプトの保存と、実行時PNGの寸法・色・アルファ・透過合成検査を分けている。
新しい生成で置き換える場合はこの原画を保持し、別名の原画を追加してrecipeの参照を変更する。

原画の対象順は、手回しドリル、金属のこぎり、金属やすり、金工ハンマー、裁縫セット、携帯調理セット、木工のこぎり、加工用鉄材、清潔な布、革片、糸、木炭、木柄、制作ストレージ。
制作ストレージは閉状態の基本画像のみ。開状態の専用画像は作っておらず、従来どおり実行時の印による表示を使う。
